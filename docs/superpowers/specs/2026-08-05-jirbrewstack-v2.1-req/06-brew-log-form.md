# 06 · ฟอร์มบันทึกการชง

กลุ่ม: บันทึก · ต้องรอ: 01, 03, 05 · ประมาณ 1.5 วัน
[กลับไป roadmap](../2026-08-05-jirbrewstack-v2.1-roadmap.md)

## ปัญหา

v2 ตั้งใจไม่เก็บบันทึกอะไรเลย บันทึกจริงอยู่ที่ Notion ซึ่งแปลว่าต้องสลับแอปตอนมือเปียกและต้องพิมพ์ค่าที่แอปคำนวณให้ซ้ำอีกรอบ

**ข้อบังคับที่สำคัญที่สุดของ item นี้: การจดต้องไม่ผูกกับ timer** เจ้าของบางครั้งไม่ได้ใช้ timer ในแอปเลย ใช้ timer ข้างนอกแทน ถ้าฟอร์มบันทึกโผล่มาแค่ตอน timer จบ ฟีเจอร์นี้จะไม่ถูกใช้เหมือนที่ timer ไม่ถูกใช้

## ต้องได้อะไร

1. **ทางเข้า 2 ทาง**
   - ปุ่ม "บันทึกการชง" บนการ์ดสูตร กดได้ตลอดเวลา ไม่ต้องเคยเข้า timer
   - ตอน timer กดจบขั้นสุดท้าย
2. **ค่าที่เติมมาให้ล่วงหน้า**: `inputs` (4 ตัวแปร + เครื่อง), `picks` (ค่าที่เลื่อน slider เลือกไว้), `resolved` (ช่วงที่สูตรคำนวณได้) ถ้ามาจาก timer ให้เติมเวลาจริงต่อขั้นจาก item 01 ลงในช่อง `actual` ถ้าไม่ได้มาจาก timer ช่องเวลาปล่อยว่างให้กรอกเอง
3. **`actual` แก้ได้ทุกช่อง** อุณหภูมิจริง เบอร์บดจริง เวลาแช่หรือเวลากดจริง bypass จริง โดสจริง น้ำจริง ค่าที่แอปแนะนำกับค่าที่ทำจริงต่างกันเสมอ และช่องว่างระหว่างสองอันนี้คือข้อมูลทั้งหมดที่มีค่า
4. **คะแนน 1 ถึง 5** และ **โน้ตรสเป็นข้อความอิสระ** ทั้งคู่ไม่บังคับ
5. เขียน 1 doc ลง `users/{uid}/brews` ตาม schema ใน roadmap โดย **`beanSnapshot` คือค่าเมล็ด ณ ตอนนั้น** ไม่ใช่แค่ `beanId` และ `resolved` เก็บค่าที่คำนวณได้จริง ไม่ใช่แค่ input
6. ไม่ login: ปุ่มยังอยู่ แต่กดแล้วบอกว่าต้อง login ก่อน ห้ามซ่อนปุ่มเงียบๆ เพราะนี่เป็นเหตุผลที่ควรจะสมัคร
7. ออฟไลน์: กดบันทึกแล้วบอกว่าบันทึกแล้ว Firestore คิวส่งให้เองตอนกลับมาออนไลน์ ห้ามขึ้น error
8. บันทึกเสร็จแล้วกลับไปหน้าสูตร พร้อมยืนยันสั้นๆ ว่าจดแล้ว

## ต้องไม่ทำอะไร

- ไม่มีรูปถ่าย
- ไม่มี SCA flavor wheel ไม่มีการให้คะแนนแยกเป็นมิติ (acidity, body, sweetness) โน้ตอิสระพอ ถ้าวันหนึ่งอยากได้ค่อยเพิ่มตอนรู้ว่าจะเอาไปทำอะไร
- ไม่มี TDS ไม่มี extraction yield ไม่มีค่าน้ำ
- ไม่แนะนำอะไรทั้งสิ้นหลังบันทึก ไม่บอกว่าครั้งหน้าควรปรับอะไร นั่นเป็นเรื่องของรอบ 5 ที่ยังไม่ทำ
- ไม่แก้บันทึกเก่า (item 07 เป็นคนตัดสินว่าจะให้แก้หรือลบได้ไหม)

## จุดที่ต้องตัดสินตอน design

- ฟอร์มยาวพอสมควร ต้องตัดสินว่าอะไรอยู่ชั้นแรกและอะไรอยู่ใต้ "ขั้นสูง" ตามหลักการซ่อนของยาก ข้อเสนอ: คะแนนกับโน้ตอยู่ชั้นแรก (จดเร็วสุดคือแค่สองอันนี้) ค่า `actual` ทั้งหมดอยู่ใต้ "ขั้นสูง" ที่กางไว้แล้วถ้ามาจาก timer
- timer ส่งเวลาจริงมายังไงเมื่อฟอร์มอาจถูกเปิดจากคนละที่ (ผ่าน state ใน App.jsx หรือ prop ตรง)
- `picks` ปัจจุบันมีอะไรบ้าง ต้องไปดูจาก `defaultPick`/`sliderBounds` ใน `brew.js` ให้ครบก่อนออกแบบช่อง `actual`

## วัดผลยังไง

- ไม่เคยเข้า timer เลย กดบันทึกจากการ์ดสูตร: บันทึกได้ครบ
- เข้า timer จบครบทุกขั้นแล้วบันทึก: เวลาจริงต่อขั้นถูกเติมมาให้ ไม่ใช่เวลาเป้า
- แก้เมล็ดในคลังหลังบันทึกไปแล้ว: บันทึกเก่ายังแสดงค่าเมล็ดแบบเดิม
- ปิดเน็ตแล้วบันทึก: ขึ้นว่าบันทึกแล้ว เปิดเน็ตแล้วเช็ค Firestore: doc อยู่ครบ
- ไม่ login กดบันทึก: บอกให้ login ไม่จอขาว ไม่เงียบ
