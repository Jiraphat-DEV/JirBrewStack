# 03 · Google login

กลุ่ม: บัญชี · ต้องรอ: 02 · ประมาณ 1 วัน
[กลับไป roadmap](../2026-08-05-jirbrewstack-v2.1-roadmap.md)

## ปัญหา

ทุกอย่างที่เก็บข้อมูลรายคน (คลังเมล็ด, บันทึกการชง, override) ต้องรู้ว่าใครเป็นใคร แต่แอปยังไม่มีแนวคิดเรื่องผู้ใช้เลย

ข้อบังคับที่สำคัญกว่าตัวฟีเจอร์: การเพิ่ม login ห้ามทำให้ของเดิมต้องมีบัญชี

## ต้องได้อะไร

1. Firebase Auth ด้วย Google provider **อย่างเดียว** ไม่มี email/password ไม่มี anonymous auth
2. ปุ่ม login อยู่ใน header ตอนไม่ login พอ login แล้วกลายเป็นรูปโปรไฟล์ที่กดแล้วมีปุ่มออกจากระบบ
3. **ตอนไม่ login ทุกอย่างที่ v2 ทำได้ต้องยังทำได้ครบ**: เลือกเครื่อง, เลือก 4 ตัวแปร, ดูการ์ดสูตร, เลื่อน slider, เข้า timer, ดูตารางแก้รส, ใช้ตัวแปลงหน่วยบด ห้ามมีอะไรถูกล็อกหรือขึ้นป้ายชวนสมัคร
4. login ครั้งแรกสร้าง doc `users/{uid}` ด้วย `displayName`, `photoURL`, `createdAt` login ครั้งถัดไปไม่เขียนทับ
5. สถานะ login อยู่ข้ามการรีเฟรชและข้ามการปิดเบราว์เซอร์
6. ระหว่างที่ยังไม่รู้ว่า login อยู่หรือเปล่า (auth state ยังไม่ resolve) แอปต้องแสดงหน้าปกติได้เลย ห้ามมีจอโหลดคั่น
7. login ไม่สำเร็จ (ผู้ใช้ปิด popup, ไม่มีเน็ต, provider ล่ม): อยู่สถานะไม่ login ต่อ แอปยังใช้ได้ครบ แสดงข้อความสั้นๆ
8. เปิด Google provider ใน Firebase console และใส่ authorized domain ให้ครบ (`jirbrewstack.web.app`, `localhost`)

## ต้องไม่ทำอะไร

- ไม่มีหน้าโปรไฟล์ ไม่มีการตั้งชื่อเอง ใช้ชื่อกับรูปจาก Google ตรงๆ
- ไม่มีปุ่มลบบัญชี (ถ้าวันหนึ่งต้องมีเพราะเหตุผลด้านข้อมูลส่วนบุคคล ค่อยทำเป็น item แยก)
- ไม่มีการเก็บ email ลง Firestore เก็บเท่าที่ใช้แสดงผลจริงคือชื่อกับรูป
- ไม่ทำ redirect flow ใช้ popup ถ้า popup ใช้ไม่ได้บนบางเบราว์เซอร์ค่อยว่ากัน

## จุดที่ต้องตัดสินตอน design

- `firebase` SDK เข้ามาเป็น dependency แรกของโปรเจกต์ ต้อง import แบบ modular และเช็คว่า bundle โตขึ้นเท่าไหร่จริง
- config ของ Firebase (apiKey ฯลฯ) เป็นค่าที่เปิดเผยได้อยู่แล้ว แต่ต้องตัดสินว่าจะฝังในโค้ดหรือผ่าน `VITE_*` env (deploy.yml มี `VITE_API_URL`/`VITE_ENV` ค้างอยู่แล้ว)
- auth state จะอยู่ตรงไหนของ `App.jsx` ที่ตอนนี้ถือ state ทั้งหมดไว้เอง
- header ตอนนี้มีปุ่มสลับ "สูตร"/"แก้รส" อยู่แล้ว และซ่อนตัวเองตอนกำลังชง ปุ่ม login จะไปอยู่ตรงไหนโดยไม่ชนของเดิม

## วัดผลยังไง

- เปิดแอปแบบ incognito ไม่ login: ทำครบทุกอย่างที่ v2 ทำได้ ไม่เจอป้ายชวนสมัครสักที่
- login สำเร็จแล้วรีเฟรช: ยัง login อยู่
- login แล้วเช็คใน Firestore: มี doc `users/{uid}` และ login ซ้ำแล้ว `createdAt` ไม่เปลี่ยน
- ปิด popup ทิ้งกลางคัน: แอปไม่ค้าง ไม่ขึ้น error ค้างจอ ยังใช้งานต่อได้
- ปิดเน็ตแล้วกด login: ขึ้นข้อความบอก ไม่จอขาว
- ผู้ใช้ A login แล้วอ่าน `users/B` ไม่ได้ (ยืนยันซ้ำกับเทส rules ของ item 02)
