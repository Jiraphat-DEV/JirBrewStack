# 07 · ประวัติการชง และชงซ้ำ

กลุ่ม: บันทึก · ต้องรอ: 06 · ประมาณ 1.5 วัน
[กลับไป roadmap](../2026-08-05-jirbrewstack-v2.1-roadmap.md)

## ปัญหา

item 06 เขียนบันทึกลง Firestore ได้แล้วแต่ไม่มีอะไรอ่านมันเลย บันทึกที่อ่านไม่ได้ก็เท่ากับไม่ได้บันทึก

และ "ชงซ้ำครั้งที่ดี" คือสิ่งที่ผู้ใช้แอปกาแฟทุกเจ้าต้องการจริงๆ ไม่ใช่การมีข้อมูลสวยงามไว้ดู

## ต้องได้อะไร

1. หน้า "ประวัติ" เข้าจาก header ตอน login แล้ว รายการเรียงใหม่สุดขึ้นก่อน แต่ละแถวเห็น: วันที่, ชื่อเมล็ด, เครื่อง, คะแนน
2. กดแถวแล้วเห็นบันทึกเต็ม: 4 ตัวแปร, ค่าที่แอปแนะนำ, ค่าที่ทำจริง, เวลาต่อขั้น, คะแนน, โน้ต **แสดงค่าที่แอปแนะนำกับค่าที่ทำจริงคู่กันให้เห็นส่วนต่าง** ไม่ใช่แสดงแค่ค่าใดค่าหนึ่ง
3. **ปุ่ม "ชงซ้ำ"** โหลด `inputs` กับ `picks` ของบันทึกนั้นกลับเข้าหน้าสูตร แล้วพาไปที่การ์ดสูตร
4. **การชงซ้ำต้องคำนวณสูตรใหม่จาก ruleset ปัจจุบัน ไม่ใช่เอา `resolved` เก่ามาแสดง** ถ้า ruleset เปลี่ยนไปแล้วผู้ใช้ต้องได้ของใหม่ และถ้าค่าที่ได้ต่างจากที่บันทึกไว้ ต้องบอกว่าต่างตรงไหน ไม่ใช่เงียบ
5. จากหน้าเมล็ดในคลัง กดดูได้ว่าเคยชงถุงนี้กี่ครั้งและครั้งไหนบ้าง
6. ลบบันทึกได้ (ลบจริง ไม่ใช่ archive เพราะไม่มีอะไรอ้างถึงบันทึก)
7. โหลด 30 รายการแรก แล้วมีปุ่มโหลดเพิ่ม
8. หน้าว่างตอนยังไม่เคยบันทึก ต้องบอกว่าจะเริ่มบันทึกได้ยังไง
9. ทำงานออฟไลน์ได้เท่าที่ Firestore cache มีอยู่

## ต้องไม่ทำอะไร

- ไม่มีกราฟ ไม่มีสถิติ ไม่มีแนวโน้ม ไม่มี dial-in arc นั่นคือรอบ 5 ที่ยังไม่ทำ
- ไม่มี export เป็น CSV หรือ PDF
- ไม่แก้บันทึกเก่า แก้บันทึกได้แปลว่าประวัติไม่ตายตัวอีกต่อไป ซึ่งขัดกับหลักการข้อ 11 ถ้าจดผิดให้ลบแล้วจดใหม่
- ไม่มีการค้นหาด้วยข้อความ กรองด้วยเมล็ดพอ
- ไม่แสดงบันทึกของคนอื่น ไม่มีการแชร์บันทึก

## จุดที่ต้องตัดสินตอน design

- การเทียบ `resolved` เก่ากับสูตรที่คำนวณใหม่ตอนกดชงซ้ำ จะเทียบทุก field หรือเฉพาะ field หลัก และแสดงส่วนต่างยังไงให้อ่านง่าย
- index ที่ Firestore ต้องการสำหรับ query "บันทึกของเมล็ดนี้ เรียงตามวันที่" ต้องเพิ่มลง `firestore.indexes.json`
- การกรองตามเมล็ดจะ query แยกหรือกรองจากชุดที่โหลดมาแล้ว ถ้า query แยกจะได้ครบแม้บันทึกเยอะ แต่ต้องมี index
- `beanSnapshot` ใช้แสดงชื่อ แต่การกรองใช้ `beanId` ต้องระวังกรณีบันทึกที่ไม่ได้ผูกกับเมล็ดเลย (`beanId` ว่าง)

## วัดผลยังไง

- บันทึก 3 ครั้งแล้วเปิดประวัติ: เห็นครบ 3 เรียงใหม่สุดก่อน
- เปิดบันทึกที่ค่าจริงต่างจากค่าแนะนำ: เห็นทั้งสองค่าคู่กัน
- กดชงซ้ำ: กลับไปหน้าสูตรพร้อมค่าเดิม
- แก้ ruleset ให้อุณหภูมิเปลี่ยน แล้วกดชงซ้ำบันทึกเก่า: ได้ค่าใหม่ และมีข้อความบอกว่าต่างจากที่บันทึกไว้
- เก็บเมล็ดเข้ากรุแล้วเปิดประวัติ: บันทึกเก่ายังแสดงชื่อเมล็ดได้ปกติ
- ลบบันทึก: หายจากรายการและหายจาก Firestore
- login ด้วยบัญชีอื่น: ไม่เห็นประวัติของบัญชีแรก
