# 08 · ลิงก์แชร์สูตร

กลุ่ม: แชร์ · ต้องรอ: ไม่ต้องรออะไร · ประมาณ 1 วัน
[กลับไป roadmap](../2026-08-05-jirbrewstack-v2.1-roadmap.md)

## ปัญหา

ตอนนี้ถ้าอยากบอกเพื่อนว่าชงถุงนี้ยังไง ต้องอ่านตัวเลขให้ฟังทีละตัวหรือแคปหน้าจอส่ง แล้วเพื่อนก็ต้องกดตามเองอยู่ดี

## ต้องได้อะไร

1. ปุ่ม "คัดลอกลิงก์" บนการ์ดสูตร
2. **ลิงก์พกค่าที่คำนวณเสร็จแล้ว ไม่ใช่แค่ 4 ตัวแปร** เหตุผลมี 2 ชั้น
   - คนรับที่มี override ของตัวเอง (item 11) จะได้ตัวเลขไม่เหมือนคนส่ง
   - พอ global ruleset เปลี่ยนทีหลัง ลิงก์เก่าจะเปลี่ยนค่าเงียบๆ ทั้งที่คนส่งคิดว่าส่งสูตรตายตัวไปแล้ว
3. ในลิงก์ต้องมีพอที่จะแสดงการ์ดและเข้า timer ได้: เครื่อง, dose, water, ค่าที่เลือกทุกตัว, ช่วงที่แนะนำ, bypass, ขั้นตอน และ **ป้ายชื่อของ 4 ตัวแปรไว้แสดงว่านี่คือสูตรของเมล็ดแบบไหน**
4. **มีเลข format version ในนั้น** ถ้าวันหนึ่งโครงสร้างเปลี่ยน ลิงก์เก่าต้องรู้ตัวว่าอ่านไม่ได้แทนที่จะอ่านผิด
5. เปิดลิงก์แล้วเห็นการ์ดสูตรในโหมด "สูตรที่แชร์มา" อ่านอย่างเดียว มี 2 ทางไปต่อ: **"เริ่มชง"** เข้า timer ได้เลย และ **"ใช้เป็นของฉัน"** โหลดค่าเข้าหน้าสูตรปกติเพื่อแก้ต่อ
6. **ไม่ต้อง login ทั้งฝั่งส่งและฝั่งรับ ไม่แตะ Firestore เลย**
7. ลิงก์ที่แกะไม่ออก หรือ version ไม่รู้จัก: บอกว่าลิงก์ใช้ไม่ได้แล้วเปิดหน้าสูตรปกติ ห้ามจอขาว
8. ความยาวลิงก์ต้องรอดจากการส่งผ่านแชท เป้าหมายคือไม่เกิน 1,500 ตัวอักษร
9. บนเครื่องที่ไม่มี clipboard API ต้องมีทางเอาลิงก์ออกไปได้อยู่ดี

## ต้องไม่ทำอะไร

- ไม่มี QR code (ถ้าอยากได้ค่อยเพิ่ม ตอนนี้ยังไม่มีใครขอ)
- ไม่บันทึกสูตรที่แชร์ลง Firestore ไม่มีตัวนับว่ามีคนเปิดกี่ครั้ง ไม่มีลิงก์สั้น
- ไม่มีคลังสูตรสาธารณะ ไม่มีการเบราว์สูตรคนอื่น
- ไม่แชร์บันทึกการชง ไม่แชร์ override
- ไม่ทำ Open Graph preview หรือ meta tag รายสูตร (ต้องมี server render ถึงจะทำได้ ไม่คุ้ม)

## จุดที่ต้องตัดสินตอน design

- วิธี encode ที่ให้ URL สั้นและปลอดภัยกับ URL (base64url ของ JSON ที่ตัด field ว่างทิ้ง แล้ววัดความยาวจริงกับสูตรที่ยาวที่สุดคือ Delter 3 จังหวะ)
- อ่าน query param ตอน mount ใน `App.jsx` โดยไม่เพิ่ม router และต้องล้าง param ออกจาก URL หลังอ่านแล้วหรือไม่ (ถ้าไม่ล้าง กดใช้เป็นของฉันแล้วรีเฟรชจะเด้งกลับ)
- โหมดอ่านอย่างเดียวจะ reuse `RecipeCard` เดิมหรือทำตัวแยก การ์ดเดิมมี slider ซึ่งไม่ควรขยับได้ในโหมดนี้

## วัดผลยังไง

- คัดลอกลิงก์แล้วเปิดใน incognito: เห็นตัวเลขทุกตัวตรงกับต้นทาง
- แก้ `brewing-rules.js` ให้อุณหภูมิเปลี่ยน แล้วเปิดลิงก์เดิม: ตัวเลขยังเป็นของเดิม
- กด "เริ่มชง" จากลิงก์: เข้า timer ได้ ขั้นตอนถูกต้อง
- กด "ใช้เป็นของฉัน": ค่าเข้าหน้าสูตรและแก้ต่อได้
- แก้ตัวอักษรในลิงก์มั่วๆ: ขึ้นข้อความบอก ไม่จอขาว
- วัดความยาวลิงก์ของสูตรที่ยาวที่สุด: ไม่เกิน 1,500 ตัวอักษร
